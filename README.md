# Tic-Tac-Toe Game

A simple two-player Tic-Tac-Toe game built with HTML, CSS and JavaScript.

## Features
- Two-player gameplay
- Win detection
- Draw detection
- Restart button

## How to Run
Open `index.html` in a web browser.

## Technologies
- HTML
- CSS
- JavaScript
